# subtitle_sync.py — 영상/자막 싱크 일괄 점검·보정

폴더 안의 영상과 자막을 짝지어, 영상 음성의 대사 구간과 자막 표시 구간을 비교해 싱크를 맞춥니다.

- 지원 자막: `.smi`, `.srt`, `.ass`, `.ssa` (UTF-8 / CP949 / UTF-16 자동 판별, 원본 인코딩 유지)
- 보정 종류
  - **전체 시간 이동**: 처음부터 끝까지 일정하게 밀린 경우
  - **프레임레이트 비율**: 23.976 / 24 / 25 / 29.97 fps 차이로 갈수록 벌어지는 경우
  - **구간별 보정** (`--split`): 중간 광고 컷 등으로 구간마다 어긋난 정도가 다른 경우
- 원본 자막은 건드리지 않고 `파일명.synced.확장자`로 새로 저장합니다.
- 결과는 폴더 안의 `subtitle_sync_report.csv`에 정리됩니다 (엑셀로 열 수 있음).

## 준비

1. Python 3.8 이상
2. `pip install numpy`
3. ffmpeg 설치 후 PATH 등록 (명령 프롬프트에서 `ffmpeg -version` 이 실행되어야 함)

## 사용법

```powershell
# 1) 점검만 (파일을 만들지 않고 보고서만 생성)
python subtitle_sync.py "F:\[애니]\[일본] 명탐정 코난" --check

# 2) 보정 파일 생성
python subtitle_sync.py "F:\[애니]\[일본] 명탐정 코난"

# 3) 광고 컷 등 구간별 차이까지 보정
python subtitle_sync.py "F:\[애니]\[일본] 명탐정 코난" --split
```

| 옵션 | 설명 |
| --- | --- |
| `--check` | 점검만 하고 보정 파일은 만들지 않음 |
| `--split` | 구간마다 어긋남이 다르면 구간별로 따로 보정 |
| `--recursive` | 하위 폴더까지 검사 |
| `--overwrite` | 이미 있는 `.synced` 파일을 덮어씀 |
| `--force` | 신뢰도가 낮아도 보정 파일을 만듦 |
| `--no-ratio` | 프레임레이트 비율 보정을 시도하지 않음 |
| `--max-offset 초` | 찾을 최대 어긋남 (기본 120초) |
| `--suffix 문자열` | 결과 파일 이름에 붙일 말 (기본 `.synced`) |

## 파일 짝 규칙

자막 이름(확장자 제외)이 영상 이름과 같거나, 영상 이름 뒤에 `.ko`, `.kor` 같은 꼬리가 붙은 경우 짝으로 봅니다.

- `코난 001화.mkv` ↔ `코난 001화.smi`, `코난 001화.ko.srt`

## 보고서의 판정

| 판정 | 의미 |
| --- | --- |
| 정상 | 어긋남이 0.1초 미만이라 보정하지 않음 |
| 보정 필요 | 보정 파일을 만듦 (`--check`일 때는 만들지 않음) |
| 구간별 보정 | `--split`으로 구간마다 다른 값으로 보정함 |
| 판단불가 | 음성과 자막의 일치도가 낮아 자동 보정하지 않음. 직접 확인 필요 |
| 짝 없음 | 같은 이름의 영상이 없음 |
| 오류 | 오디오 추출 실패 등. 메모 칸 참고 |

- **신뢰도(PSR)**: 8 이상이면 확실, 5~8이면 결과 확인 권장, 5 미만이면 판단불가.
- **구간별 오프셋**: 2분 단위로 따로 잰 값입니다. 값 뒤의 `?`는 그 구간의 신뢰도가 낮다는 뜻입니다.
  값이 중간에 크게 바뀌면 광고 컷 등이 원인이므로 `--split`을 쓰세요.

## 한계

- 음성 에너지를 기준으로 하므로, 배경음악이 대사보다 훨씬 큰 장면이 많으면 신뢰도가 낮아질 수 있습니다.
- 영상 안에 들어있는 내장 자막 트랙은 다루지 않고, 별도 자막 파일만 처리합니다.
- `--split` 사용 시 컷 경계 바로 옆의 대사 한두 개는 틀릴 수 있습니다.
