# subtitle_sync.py — 영상/자막 싱크 일괄 점검·보정·검증

폴더(하위 폴더 포함) 안의 영상과 자막을 짝지어, 영상 음성의 대사 구간과 자막 표시 구간을 비교해 싱크를 맞춥니다.

## 처리 순서 (파일마다 자동)

1. **점검**: 원본 자막이 음성과 맞는지 검증합니다. 맞으면 손대지 않습니다 (`정상`).
2. **수정**: 간단한 방법부터 보정안을 만듭니다.
   - 프레임레이트 비율 + 이동 (비율 차이가 확인된 경우만)
   - 전체 이동
   - 구간별 보정 (광고 컷 등으로 중간에 어긋남이 바뀌는 경우)
3. **검증**: 보정한 자막을 음성과 다시 비교합니다. 남은 어긋남이 전체 0.15초, 구간별 0.5초 이내이고 일치도가 원본보다 올라야 통과입니다.
4. **재수정**: 검증에 실패하면 다음 방법으로 다시 시도합니다. 모두 실패하면 원본을 그대로 두고 `수동 확인 필요`로 표시합니다.

### 신뢰도가 낮은 파일 (앞뒤 화 비교)

배경음악·효과음이 큰 화는 신뢰도(PSR)가 낮게 나옵니다.
PSR이 2.5~5 사이면, **앞뒤 3화씩의 측정값 중 3편 이상이 0.5초 안으로 같은 오프셋**일 때만 적용합니다.
잘못 잡힌 값은 화마다 제각각이라 여러 화에서 우연히 일치하기 어렵기 때문입니다.
이 비교를 위해 파일은 이름 속 숫자 순서(1, 2, … 10, … 100)로 처리하고, 판정·저장은 3편씩 늦게 진행됩니다.

### 노래 가사 제외

♪ 등 음표가 들어간 자막과, 틈 없이 40초 이상 이어지는 자막 묶음(오프닝/엔딩 가사)은
싱크 계산에서만 빼고, 시간 보정은 모든 자막에 똑같이 적용합니다.

검증을 통과한 보정만 **원본 자막 파일에 덮어씁니다.**
덮어쓰기 전에 원본은 자막이 있는 폴더 안의 `_자막원본백업` 폴더에 한 번 보관됩니다.
다시 실행하면 항상 백업해 둔 원본을 기준으로 계산하므로, 여러 번 실행해도 보정이 누적되지 않습니다.

- 지원 자막: `.smi`, `.srt`, `.ass`, `.ssa` (UTF-8 / CP949 / UTF-16 자동 판별, 원본 인코딩 유지)
- 결과는 대상 폴더의 `subtitle_sync_report.csv`에 한 편 처리할 때마다 기록됩니다 (엑셀로 열 수 있음, 중간에 멈춰도 그때까지의 기록이 남음).

## 준비

1. Python 3.8 이상
2. `pip install numpy`
3. ffmpeg 설치 후 PATH 등록 (명령 프롬프트에서 `ffmpeg -version` 이 실행되어야 함)

## 간단 실행 (sync_subtitles.bat)

`subtitle_sync.py`와 `sync_subtitles.bat`을 같은 폴더에 두고 bat 파일을 더블클릭하면
`F:\[애니]\[일본] 명탐정 코난` 폴더(하위 폴더 포함)를 처리합니다.
다른 폴더는 그 폴더를 bat 파일 위로 끌어다 놓으면 됩니다.
Python, ffmpeg가 없으면 안내 메시지를 띄우고, numpy가 없으면 자동으로 설치합니다.

## 사용법

```powershell
# 점검만 (자막은 수정하지 않고 보고서만 생성)
python subtitle_sync.py "F:\[애니]\[일본] 명탐정 코난" --recursive --check

# 점검 → 수정 → 검증 → 재수정 후 덮어쓰기
python subtitle_sync.py "F:\[애니]\[일본] 명탐정 코난" --recursive

# 백업해 둔 원본으로 모두 되돌리기
python subtitle_sync.py "F:\[애니]\[일본] 명탐정 코난" --restore
```

| 옵션 | 설명 |
| --- | --- |
| `--recursive` | 하위 폴더까지 검사 |
| `--check` | 점검만 하고 자막은 수정하지 않음 |
| `--restore` | `_자막원본백업`의 원본 자막을 원래 위치로 되돌림 |
| `--force` | 검증을 통과하지 못해도 가장 나은 보정을 적용 |
| `--no-ratio` | 프레임레이트 비율 보정을 시도하지 않음 |
| `--no-split` | 구간별 보정을 시도하지 않음 |
| `--max-offset 초` | 찾을 최대 어긋남 (기본 120초) |

## 파일 짝 규칙

자막과 영상이 **같은 폴더**에 있고, 자막 이름(확장자 제외)이 영상 이름과 같거나
영상 이름 뒤에 `.ko`, `.kor` 같은 꼬리가 붙은 경우 짝으로 봅니다.

- `코난 001화.mkv` ↔ `코난 001화.smi`, `코난 001화.ko.srt`

## 보고서의 판정

| 판정 | 의미 |
| --- | --- |
| 정상 | 원본이 이미 맞음. 수정하지 않음 |
| 보정 완료 | 검증을 통과한 보정을 덮어씀 |
| 보정 필요 | (`--check`일 때) 검증을 통과한 보정이 있음. 아직 덮어쓰지 않음 |
| 수동 확인 필요 | 모든 보정 방법이 검증을 통과하지 못해 원본 유지 |
| 짝 없음 | 같은 폴더에 같은 이름의 영상이 없음 |
| 오류 | 오디오 추출 실패 등. 메모 칸 참고 |

- **원본 검증 / 보정 후 검증**: 일치도(높을수록 좋음), 남은 어긋남, 구간별 최대 어긋남
- **시도 내역**: 어떤 방법(찾은 오프셋)을 시도했고 왜 통과/실패했는지. 예: `전체 이동(+15.11초): 통과(앞뒤 화 4편과 일치)`

## 한계

- 검증도 같은 음성 분석으로 하므로 사람이 직접 보는 것만큼 확실하지는 않습니다. `수동 확인 필요` 파일과 몇 편은 직접 확인해 보세요.
- 합성 테스트에서 보정 결과가 정답보다 약 0.07초 늦게 나왔습니다 (체감하기 어려운 수준).
- 구간별 보정 시 컷 경계 바로 옆의 대사 한두 개는 틀릴 수 있습니다.
- 영상 안의 내장 자막 트랙은 다루지 않고, 별도 자막 파일만 처리합니다.
